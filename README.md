# E-Commerce Sales Analytics Dashboard

An interactive Streamlit dashboard for exploring e-commerce sales, revenue, profitability, product categories, regions, advertising spend, and customer ratings.

## Project Overview

This project turns a cleaned e-commerce sales dataset into an interactive analytics dashboard. It helps users investigate questions such as:

- Which product categories and regions generate the most revenue and profit?
- How do units sold and profit margins differ across categories?
- How does performance change by month and year?
- Is advertising spend linearly associated with revenue?
- Which category-region combinations may require further investigation?

The repository also includes the exploratory data analysis notebook used to inspect, clean, transform, and analyze the source data. Dashboard results recalculate when filters are changed.

## Key Features

### Interactive filters

The sidebar provides filters for:

- Year
- Month
- Product category
- Region

The **Reset all filters** control restores the complete dataset selection. Filter changes update the KPIs, charts, business insights, and filtered records together.

### KPI summaries

The dashboard reports:

- Total revenue
- Total profit
- Total units sold
- Overall profit margin

The Overview tab also includes average customer rating, average revenue per record, and average advertising spend as a percentage of revenue.

### Dashboard tabs and analysis

- **Overview:** Revenue and profit distributions, revenue by product category, revenue by region, and additional signals.
- **Performance:** Regional revenue and profit, units sold by category, profit margin by category, and category-region revenue.
- **Trends & relationships:** Monthly revenue by year, revenue by year, advertising spend versus revenue, and a numerical correlation heatmap.
- **Business insights:** Filter-aware analysis of advertising spend and revenue, category revenue, and category-region revenue.
- **Data explorer:** A table of records matching the current filters.

### Filtered data export

The Data explorer tab provides a **Download filtered data (CSV)** option for exporting the currently selected records, including calculated profit margin and advertising spend percentage fields.

## Dataset Information

The dashboard uses `ecommerce_sales_data.csv`, a dataset containing **1,000 rows and 9 columns**.

| Column | Description |
| --- | --- |
| `Year` | Sales year from 2020 through 2024 |
| `Month` | Sales month across 12 calendar months |
| `Category` | Product category |
| `Region` | Sales region |
| `Units_Sold` | Number of units sold in the record |
| `Revenue` | Revenue generated by the record |
| `Profit` | Profit generated by the record |
| `Customer_Rating` | Customer rating on a 1–5 scale |
| `Ad_Spend` | Advertising spend associated with the record |

The dataset contains six product categories and four regions:

- Categories: Beauty Products, Books, Electronics, Fashion, Groceries, and Home Decor
- Regions: East, North, South, and West

The notebook verifies that the source data has no missing values and no duplicate rows. The application still validates required columns, removes exact duplicates if encountered, normalizes text fields, and converts numeric fields safely when loading data.

### Calculated features

The application and notebook derive the following fields:

- `Month_Number`: Numeric month ordering used for chronological sorting.
- `Profit_Margin`: Profit as a percentage of revenue.
- `Ad_Spend_Percentage`: Advertising spend as a percentage of revenue.

## Installation and Setup

The following steps are suitable for Windows PowerShell.

### 1. Clone the repository

Replace `<repository-url>` with the repository URL after publishing the project.

```powershell
git clone <repository-url>
cd e-commerce-dashboard
```

### 2. Create a virtual environment

```powershell
py -m venv .venv
```

If the `py` launcher is unavailable, use:

```powershell
python -m venv .venv
```

### 3. Activate the virtual environment

```powershell
.\.venv\Scripts\Activate.ps1
```

If PowerShell prevents script activation for the current session, run:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Then activate the environment again.

### 4. Install dashboard dependencies

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Running the App

From the project directory, activate the virtual environment and run:

```powershell
streamlit run app.py
```

Streamlit will display a local URL in the terminal. Open that URL in a browser to use the dashboard.

## Usage Guide

1. Launch the application with `streamlit run app.py`.
2. Use the sidebar multiselect controls to choose years, months, product categories, and regions.
3. Review the KPI cards and charts in the Overview tab.
4. Move through the Performance, Trends & relationships, and Business insights tabs for deeper analysis.
5. Open Data explorer to inspect the filtered records.
6. Select **Download filtered data (CSV)** to export the current filtered dataset.
7. Use **Reset all filters** to restore the complete selection.

The dashboard expects `ecommerce_sales_data.csv` to remain beside `app.py`.
